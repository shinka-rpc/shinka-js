# Scenarios

`@shinka-rpc/scenarios` provides small, reusable helpers for common
communication and synchronization patterns in Shinka-RPC applications.

The package composes Shinka-RPC events and primitives to simplify application
code. It is not intended to replace general-purpose concurrency utilities or
manage connections on the application's behalf.

Explore the scenarios:

- [Wait for a connection](wait-connected.md)
- [Manage a client registry](client-registry.md)
- [Pass through events and requests](pass-through.md)
- [Coordinate resource acquisition](single-flight.md)
