# Building Blocks

Shinka-RPC includes a collection of general-purpose modules that provide reusable building blocks for its core components. These modules are independent of the RPC layer and can be used in any application.

## [Concurrency](../api-reference/concurrency/)

Provides reusable asynchronous primitives and synchronization mechanisms for coordinating concurrent operations and controlling access to shared resources.

## [Collections](../api-reference/collections.md)

Provides general-purpose data structures and collection utilities designed to simplify common data management tasks.

## [Util](../api-reference/util/)

Provides miscellaneous utilities and lightweight abstractions for common programming tasks.
